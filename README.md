# DSSI Safety job display installer

Web page that installs and sets up the job display over USB, in Chrome or
Edge on a computer: https://ognightrider555-cell.github.io/job-display-installer/

1. Pick the board.
2. Plug the display in, click **Install** and choose its port.
3. Enter the setup key you were sent, the Wi-Fi name and password, and the
   time zone, then click **Send to display**.

The firmware here contains no keys or job data. The setup key is typed into
the page and goes straight to the display over the USB cable.
