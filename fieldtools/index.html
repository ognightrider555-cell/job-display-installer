DSSI SAFETY

Field Tools Installer

1Get ready

Do this on the PocketTerm itself, connected to Wi-Fi or Ethernet with internet.

You'll need the setup key from the person who sent you this link.

2Copy the command

3Run it

Open Terminal from the taskbar or the app menu. Paste with Ctrl+Shift+V and press Enter.

When it asks, paste the setup key and press Enter. The key stays hidden while you paste it.

It takes under a minute. When it says Done, tap the DSSI Field Tools button on the taskbar.

4Updates

Run the same command again to get the newest version. Your camera settings (cameras.toml) are kept.

If something goes wrong
  • GitHub refused the setup key: paste the key again exactly, with no extra spaces.
  • GTK for Python is missing: run the sudo apt install line it shows, then the command again.
  • Could not resolve host / download failed: the PocketTerm has no internet. Check Wi-Fi.
  • Remove it: delete the dssi-field-tools folder in your home folder and the DSSI Field Tools desktop icon.
